Answer 2: Instead of storing 6 vertices, we can store 4 unique vertices and use 6 indices (0, 1, 2, 1, 3, 2) to make the two triangles. Using floats (4 bytes each), without indexing we need 
6*2*4 = 48 bytes. With indexing, we need (4*2*4) + (6*4) = 56 bytes. Using doubles (8 bytes each), without indexing we need 6 × 2 × 8 = 96 bytes. With indexing, we need (4*2*8) + (6*4) = 88 bytes.
So, indexing uses 8 more bytes with floats but saves 8 bytes with doubles. Indexing is better when the same vertices are used multiple times. On average, each vertex needs to be used more than 2 times with floats or 1.33 times with doubles to save memory.
